# Blackjack Pro Simulator & Counter 🃏

A professional-grade, interactive Blackjack utility designed to help players practice Basic Strategy and track table statistics using the Hi-Lo card counting system.

## 🚀 Features
* **Dynamic Basic Strategy Engine:** Evaluates optimal moves (Hit, Stand, Double, Split) based on dealer's upcard and player's hand.
* **Multi-Hand Support:** Simulates hand splitting with dynamic table expansion (up to 4 simultaneous hands).
* **Live Card Counter (Hi-Lo):** Keeps track of Running Count, True Count, and remaining cards.
* **Deck Limitations:** Accurate simulation of remaining card probabilities based on 1 to 6 decks. 
* **State Management:** Prevents impossible board states (e.g., drawing 5 Aces in a single-deck game).

## 🛠️ Tech Stack
Built completely serverless for maximum speed and zero hosting costs.
* **Frontend:** Vanilla HTML5, CSS3 (Responsive Grid/Flexbox design).
* **Logic:** Vanilla JavaScript (ES6+).
* **Hosting:** GitHub Pages.
